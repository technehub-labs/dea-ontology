# Patterns — Index

> **Status:** placeholder. Bodies land in Phase 5 of [CR-EO-01](../change-requests/CR-EO-01.md).

## Pattern families

1. **Upper-ontology conventions** — selection guidance for BFO / DOLCE / SUMO / EMMO / custom; integration patterns.
2. **Ontology profile declarations** — OWL 2 EL / QL / RL profile selection based on use-case characteristics.
3. **Axiomatisation depth** — how to choose between minimal-classification and rich-axiomatisation for a sector ontology.
4. **Ontology modularisation** — how to factor an ontology into importable modules.
5. **Cross-ontology mapping patterns** — declared mappings between EO assets and external ontologies (schema.org, FIBO, HL7 FHIR-RDF).

## Phase 5 deliverable targets

- ≥ 5 pattern bodies (one per family).
- Each pattern: intent, structure, example, anti-patterns, cross-references.
- Pattern bodies conform to the OpenDEA pattern template (cf. `technehub-labs/dea-catalog-patterns`).
