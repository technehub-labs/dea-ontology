# Axioms

This directory holds the three EO axioms in their own files, each with its full derivation table to the ECF 7×7 axiom grid.

The three placeholder axioms (final prose in Phase 1):

1. `axiom-01-ontological-commitment.md` — every formal assertion declares its ontological commitment.
2. `axiom-02-upper-ontology-pluralism.md` — upper-ontology choice is sector-specific, not federation-mandated.
3. `axiom-03-ontology-lifecycle-governance.md` — ontology lifecycle (versioning, deprecation, retirement) is a first-class discipline.

Each axiom file ships in Phase 1 with:
- Statement.
- ECF derivation table.
- Operational rule.
- Anti-pattern.
- Cross-references.
